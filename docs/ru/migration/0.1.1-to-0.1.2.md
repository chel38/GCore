# Миграция 0.1.1 → 0.1.2-alpha

API и protocol остаются на версии 1, но есть одно намеренное изменение export:

```lua
-- Было: string
local old = exports.gc_core:GetVersion()

-- Стало: DTO
local version = exports.gc_core:GetVersion()
local text = exports.gc_core:GetVersionString()
```

Удалите чтение `GCConfig.General.apiVersion/protocolVersion`. Используйте
`GetApiVersion()`, `GetProtocolVersion()` или `GCVersion` внутри gc_core.

Payload событий теперь exact-schema: удалите любые дополнительные поля. В
`confirmSpawn` отправляется только `decisionId`. `requestSpawn` принимает пустую
table. `reportClientError` принимает только зарегистрированный error code.

Не рассчитывайте, что retry повторит тот же decision/ped: старый ID одноразовый и
инвалидируется. Не используйте IDs как токены авторизации.

Тесты больше не загружаются production runtime. Для явного запуска используйте
`set gc_runTests 1`, а после проверки возвращайте `0`.
