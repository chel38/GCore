# Migration 0.1.1 → 0.1.2-alpha

API and protocol remain at version 1, but `GetVersion` intentionally changes from
a string to a detached DTO. Use `GetVersionString()` when a string is required.

Stop reading `GCConfig.General.apiVersion/protocolVersion`; use the explicit
version exports. Event payloads now use exact schemas. `confirmSpawn` sends only
`decisionId`, `requestSpawn` sends an empty table, and client error reports require
a registered code.

Retry creates a new one-time decision and, when possible, a new ped model. Never
use correlation/session/decision IDs as authorization secrets.

Tests no longer execute in production. Opt in with `set gc_runTests 1`, then
restore `0` after validation.
