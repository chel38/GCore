# Первый запуск / First Start

## Что происходит при запуске

При запуске `gc_core` выполняются следующие шаги:

1. Загружаются общие файлы (конфигурация, локализация, утилиты).
2. Загружается серверная часть.
3. Загружается клиентская часть.
4. Регистрируются обработчики событий.
5. Регистрируются exports.
6. Выводится сообщение о запуске.

## Ожидаемые сообщения

```text
[GreenCore] [INFO] gc_core server bootstrap loaded | version=0.1.3-alpha
[GreenCore] [INFO] gc_core 0.1.3-alpha started successfully
```

## Что происходит при подключении игрока

```text
Игрок подключается
    ↓
gc_core запускает deferrals
    ↓
Сервер проверяет имя
    ↓
Сервер собирает идентификаторы
    ↓
Сервер проверяет license
    ↓
Сервер создаёт сессию
    ↓
Сервер разрешает подключение
    ↓
Клиент сообщает о готовности
    ↓
Сервер создаёт решение о спавне
    ↓
Клиент выполняет спавн
    ↓
Сервер подтверждает
```

## Проверка работы

### 1. Игрок подключился

В консоли сервера должно появиться сообщение о подключении.

### 2. Игрок появился

Игрок должен появиться в точке из `config/spawn.lua`.

### 3. Проверка через API

В консоли сервера выполните:

```lua
print(exports.gc_core:GetVersionString())
```

Должно вывестись:

```text
0.1.3-alpha
```

## Возможные проблемы

| Проблема | Решение |
| -------- | ------- |
| Ресурс не запускается | Проверьте `fxmanifest.lua` |
| Нет сообщения о запуске | Проверьте, что `ensure gc_core` в `server.cfg` |
| Игрок не появляется | Проверьте `config/spawn.lua` |
