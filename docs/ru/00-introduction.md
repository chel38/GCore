# Введение / Introduction

## Что такое GreenCore?

GreenCore (GCore) — это минимальный модульный движок для FiveM, написанный **исключительно на Lua 5.4**.

Он отвечает за безопасный жизненный цикл игрока:

```text
Подключение → Проверку → Сессию → Готовность клиента → Спавн → Подтверждение → Отключение
```

## Главный принцип

```text
Сервер является источником истины.
Server is the source of truth.
```

Клиент **не** решает:

- можно ли подключиться;
- где появиться;
- какую модель использовать;
- завершён ли спавн.

Клиент может только:

- сообщить о готовности;
- получить решение сервера;
- выполнить разрешённое действие;
- подтвердить выполнение.

## Технологический стек

| Компонент | Технология |
| --------- | ---------- |
| Сервер    | Lua 5.4    |
| Клиент    | Lua 5.4    |
| Конфигурация | Lua 5.4 |
| Локализация | Lua 5.4 |
| Тесты     | Lua 5.4    |
| Документация | Markdown, Mermaid |
| NUI (будет добавлен позже) | TypeScript + Tailwind CSS |

> **NUI, когда будет добавлен, будет написан на TypeScript + Tailwind CSS**
> **и других современных технологиях FiveM. C# не будет использоваться.**

## Что НЕ входит в первую версию

- Регистрация, аккаунты, персонажи
- База данных
- Деньги, инвентарь, транспорт
- Чат, HUD, админ-панель
