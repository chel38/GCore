# Code of Conduct / Кодекс поведения

## Наше обещание / Our Pledge

Мы стремимся создать открытое и дружелюбное сообщество.
We aim to create an open and welcoming community.

## Наши стандарты / Our Standards

Примеры поведения, способствующие созданию позитивной среды:

- Уважительное отношение к другим / Being respectful of differing viewpoints.
- Конструктивная обратная связь / Constructive feedback.
- Сосредоточенность на том, что лучше для сообщества / Focusing on what is best for the community.

## Область применения / Scope

Этот кодекс применяется ко всем взаимодействиям в рамках проекта.
This code of conduct applies to all interactions within the project.
